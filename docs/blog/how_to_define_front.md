# 如何严谨地定义人的前方
## 关于
这是一个有趣而困难的问题，以下是我的尝试。（并感谢 `@Kavod_gatta` 对一些路线的反驳）
!!! warn
	本定义只适用于无明显缺陷的一般形态下的活体智人

## 定位：脊椎骨构成的脊柱
设一个恰当的邻域半径、恰当的成分范围（通过统计学手段），取最大联通块即可。

## 定向：上下
将前述“脊椎骨构成的脊柱”单独分离，在标准室温（300K）下将其*内部*气体与液体（包括一定大小的空腔）替换为水银。

再三维欧氏空间中取一个确定的平面（如 `xOy`），添加垂直于该平面的均匀的、$10m/s^2$ 的重力场。将前述物体放在一侧并平移直到相切，考虑重力势能最大的放法，此时得到了定向的上下，成为主方向。

## 定位：脊柱的某片段
考虑以所有垂直于主方向的平面，将脊柱分为无穷多个薄片（假定为实心），设置恰当的薄片面积变换率得到居中的一个片段。再设置恰当的比例取其中更小一块。

## 未定向：前后
考虑前述脊柱块的上下平面，将躯干（类似脊柱进行定位）割出一块，考虑平行切出的无穷多薄片（假定为实心），对于所有垂直的平面（主方向在其上，记作割平面）将所有薄片分成两部，对每个薄片放缩使得两个交点间距为单位长度，作恰当的栅格化，考虑上下长度差的平方乘以 $(x-0.5)^4$，记作 `f(x)`，`f(x)` 在主方向上的积分记作 `F(x)`。`F(x)` 取最小值时对应的割平面即标注了前后轴。

## 定向：前后
考虑前述躯干块的两种放法，单独考虑其中的原生质层，然后按“定向：上下”的第二步方法，其中有一个（尽管我不知道是较小者还是较大者）标注了前。
