# 设定集
## 世界
世界是一个巨大（真的，三千大千世界为一佛土那样，连接关系为超图）的不知道什么东西。
局部上有 Poincaré 群，以及巨大的不知道什么东西。

## 力量体系
通过**识海**获得自身特有的**灵**（本质是群），接近相应的法则（本质是无限群，可能比实数集大若干级）。

作为缺省值，凡人对应恰一个一阶群。

超凡者等级判断标准（尘世所定）：
* **巫师学徒**：*有能力*拥有最小的奇数阶非交换群（$G = <a, b>, a^3=e, a^{-1}\times b\times a=b^2$）
* **巫师**：*有能力*拥有最小的非交换单群（$A_{60}$）
* **大巫师/贤者**：拥有无限群。空间传送是利用 Lorentz 变换群的典型手段。
* **半神/大贤者**：能够直接控制法则。如*九天应元雷声普化天尊*能控制部分升华法则和秩序法则。

不存在死板的“槽位”，**灵**的数量、性质不固定，与**识海**的状态有关。

## 力量使用
**奇迹**：直接使用**灵**同化状态。

**亵渎**：对**法则**使用**奇迹**。

**附灵**：将一个或多个元素（最好是生成元）嫁接到其它的群上（暂态自由群），进行作用。

* **法术**：在较低层次，使用**灵**撬动其接近的**法则**，如：
> **戏法/学徒法术** 火球术
> 
> 效果：\
> 产生一个任意大小的火球进行攻击。
> 
> 原理：\
> 使用 $Z_2$ 撬动**显形法则**，让空间中游离的魔法因子将空气显形为等离子态。此时可添入其它材料。\
> 使用 $Z_2\times Z_2$ 撬动**屏障法则**收束火焰。\
> 使用一阶群撬动**实体法则**，操纵其前进。

## 法则
### 世界层面
**设定法则**：法则总称。本质是这个设定集。
* 下位：**信息法则**

**升华法则**：与**新生**、**启迪**，**登神**，新的法则有关。显然是最初的法则。不知道本质是什么，不知道是不是活的。

**创造法则**：
* 下位：**实体法则**

**门径法则**：
* 下位：**召唤法则**、**链接法则**

### 单体世界层面
按世界不同，可能有数目与内容的差异。

**场域法则**：与时空有关。

**秩序法则**：与法术有关。本质是 FSM（Finite State Machine/有限状态自动机）。

**神秘法则**：与神秘有关。
* 下位：相似律、接触律、界

**置换法则**：与奇迹、亵渎、附灵有关。
* 在较低的角度上看为**等价交换法则**

**显形法则**：是**创造法则**的下位，又称**隐形法则**
* 下位：**屏障法则**、**隐匿法则**、**阳法则**、**阴法则**

**物质法则**：物理。

## 修炼
**启迪**：升华。由升华者/使用升华之物（这包括世界）举行含有升华象征的仪式。

**稳固状态**：冥想。 在识海中构建接近于当前自身群的刻画，如：
* $Z_2$：阴阳太极鱼、卡片翻转
* $A_4$：正四面体旋转

这个刻画本质上是需要下沉到潜意识，因此可以：同时冥想多个场景。放在不同的位置会有区别，与神秘法则有关。

**晋升**：冥想，逐渐过渡观想内容。衍生出合成群列法、置换法。
