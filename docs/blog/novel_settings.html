    设定集

    世界

    世界是一个巨大（真的，三千大千世界为一佛土那样，连接关系为超图）的不知道什么东西。 局部上有 Poincaré 群，以及巨大的不知道什么东西。

    力量体系

    通过识海获得自身特有的灵（本质是群），接近相应的法则（本质是无限群，可能比实数集大若干级）。

    作为缺省值，凡人对应恰一个一阶群。

    超凡者等级判断标准（尘世所定）：

    • 巫师学徒：有能力拥有最小的奇数阶非交换群（G = <a, b>, a^3=e, a^{-1}\times b\times a=b^2）

    • 巫师：有能力拥有最小的非交换单群（A_{60}）

    • 大巫师/贤者：拥有无限群。空间传送是利用 Lorentz 变换群的典型手段。

    • 半神/大贤者：能够直接控制法则。如九天应元雷声普化天尊能控制部分升华法则和秩序法则。

    不存在死板的“槽位”，灵的数量、性质不固定，与识海的状态有关。

    力量使用

    奇迹：直接使用灵同化状态。

    亵渎：对法则使用奇迹。

    附灵：将一个或多个元素（最好是生成元）嫁接到其它的群上（暂态自由群），进行作用。

    • 法术：在较低层次，使用灵撬动其接近的法则，如：

    戏法/学徒法术 火球术

    效果：

    产生一个任意大小的火球进行攻击。

    原理：

    使用 Z_2 撬动显形法则，让空间中游离的魔法因子将空气显形为等离子态。此时可添入其它材料。

    使用 Z_2\times Z_2 撬动屏障法则收束火焰。

    使用一阶群撬动实体法则，操纵其前进。

    秩序法则：与法术有关。本质是 FSM（Finite State Machine/有限状态自动机）。

    修炼

    启迪：升华。由升华者/使用升华之物（这包括世界）举行含有升华象征的仪式。

    稳固状态：冥想。 在识海中构建接近于当前自身群的刻画，如：

    • Z_2：阴阳太极鱼、卡片翻转

    晋升：冥想，逐渐过渡观想内容。衍生出合成群列法、置换法。
